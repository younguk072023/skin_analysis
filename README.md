# SinGAN 생성 건선 영상 분석 및 데이터 증강 효과 비교

## 프로젝트 개요

SinGAN으로 생성한 건선 영상이 실제 영상의 중증도 관련 색상·질감 특성을 얼마나 재현하는지 분석하고, 생성 영상을 학습 데이터에 추가했을 때 중증도 분류 성능이 어떻게 달라지는지 비교했습니다.

이 저장소는 **생성된 영상의 특징 분석과 분류 실험 코드**를 담고 있습니다. SinGAN 모델의 학습 및 이미지 생성 코드는 포함하지 않습니다.

## 분석 과정

1. 실제 영상의 정답 마스크와 생성 영상의 분할 마스크를 이용해 병변과 주변 피부를 구분했습니다.
2. CIELAB·ITA 기반 색상 특징 20개와 GLCM·LBP 기반 질감 특징 18개, 총 38개 특징을 추출했습니다.
3. 실제 영상과 생성 영상에서 특징 분포 및 중증도와의 관계를 비교했습니다.
4. 동일한 실제 영상 검증 폴드를 유지한 5-Fold 교차검증에서 **Real-only**와 **Real+GAN** 학습 결과를 비교했습니다. 생성 영상은 학습 폴드에만 추가했습니다.

## 주요 결과

프로젝트 실험 기록 기준, 38개 특징 중 36개에서 실제·생성 영상의 중증도 상관 방향이 일치했습니다. XGBoost의 Macro-F1은 Real-only **0.8345**에서 Real+GAN **0.8842**로 향상됐습니다. 다만 상관 방향이 다른 두 특징을 제외해도 성능이 추가로 개선되지는 않았습니다.

## 주요 파일

| 파일 | 역할 |
| --- | --- |
| `preprocessing.py`, `features/` | 영상·마스크 전처리와 색상·질감 특징 추출 |
| `analysis.py` | 특징과 중증도의 관계 분석 |
| `real_gan.py` | 실제 영상과 생성 영상의 특징 비교 |
| `ML.py` | 실제 영상만 사용한 분류 실험 |
| `real_gan_ml.py` | Real-only와 Real+GAN의 5-Fold 성능 비교 |
| `models/` | 분류 모델 정의 |

## 실행 시 참고

입력 영상·마스크와 특징 CSV는 저장소에 포함돼 있지 않습니다. 스크립트에는 실험 당시의 로컬 절대경로가 사용되므로, 실행 전 데이터 경로를 사용 환경에 맞게 수정해야 합니다. 공개된 코드와 데이터만으로 위 결과 수치를 바로 재현할 수는 없습니다.
